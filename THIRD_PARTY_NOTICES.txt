The generated appendix uses the official CycloneDX SBOMs shipped in the
pydantic-core and jiter wheels to identify their statically linked Rust crates.
It records each crate name, version, source hash, author, and license expression,
then reproduces the original crate notices. Byte-identical license bodies are
stored once with every component association retained; the raw dependency-graph
metadata and its upstream build paths are not copied into the portable package.

Before a public binary release, the distributor must also place the exact
corresponding Qt/PySide source archives at a distributor-controlled location
beside the binary, or provide a valid written source offer. An upstream-only
link is not sufficient under Qt's published community-license guidance. The
final GitHub source-asset links or offer contact are therefore a release-time
requirement and are not fabricated in this local build.

The CPython runtime supplies `libssl-3.dll` and `libcrypto-3.dll`; the Apache
License 2.0 text included in the Python acknowledgements and this appendix
applies to that OpenSSL runtime. Python's license file also contains the terms
for Microsoft distributable code, bzip2, libffi, and other bundled components.

Extension tools placed in `DLC` are separate programs and are not included in
the Studio distribution. Each extension is governed by the license and notices
provided by its own distributor.
