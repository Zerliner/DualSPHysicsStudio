# DSS Mesh Doctor

这是与 DualSPHysics Studio v1.0.3 内置预检使用同一检查核心的独立只读
DLC。它适用于在不启动 Studio 的情况下检查 STL 或 legacy VTK。

## 检查范围

- 文件大小、点/单元数量和保守内存预算。
- legacy VTK 的格式头与声明数量。
- 预算内 STL 的唯一顶点、边界边、非流形边和连通分量。
- 重复面、退化面、相邻面方向和 STL 法向一致性。
- 表面积、包围盒尺寸；封闭表面同时给出体积。
- JSON 报告导出。

开放表面不一定是错误：地形或片状边界可能有意保持开放。非流形、重复、
退化或方向不一致会标为需要人工确认，但工具不会自动修复网格。
体积按各封闭连通分量的绝对有向体积求和；本版不检测自相交、嵌套壳体的布尔
含义或容差范围内的近似重合，因此体积仍需结合模型语义复核。

为控制内存，深度拓扑检查最多处理 100,000 个三角形和 256 MiB 文件；超出
预算时仍保留格式、规模和资源风险预检，并明确标记拓扑检查未执行。
